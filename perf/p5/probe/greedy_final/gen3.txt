Explain step by step how TCP slow start and congestion avoidance work.

TCP slow start and congestion avoidance are two mechanisms used by the Transmission Control Protocol (TCP) to manage the flow of data between a sender and a receiver. These mechanisms help to prevent network congestion and ensure efficient data transmission.

Step 1: Slow Start
In the slow start phase, the sender gradually increases the amount of data it sends to the receiver. This is done to avoid overwhelming the network with a large amount of data at once. The sender starts with a small amount of data, typically one packet, and gradually increases the amount of data it sends as it receives acknowledgments from the receiver.
