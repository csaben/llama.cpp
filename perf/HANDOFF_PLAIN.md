## Finished

Final code 6d600fc, final results tag p6p-final-215tok. GPU0 reached 215.38 +/- 1.33 tok/s at depth 0. Four-depth results, the original GPU0 baseline and the same-binary control are in [RESULTS_PLAIN.md](RESULTS_PLAIN.md). The default build completed. All 1108 affected CUDA0 backend cases passed. PPL was 3.0530 / 4.1979. The attention change altered one of 64 teacher-forced argmaxes; the expert and router changes alone reproduced all logit bits.

The measured decoder takes 4.643 ms/token. Even giving a side stream a contiguous token's worth of weights before routing was available and omitting all 193 quantized dot products took 4.11 ms in the best tested configuration. Nsight confirmed real overlap between that read and the decoder kernels. A cooperative expert grid and the attention prefetch both slowed real decode. This is evidence about the tested schedules, not a universal RTX 3090 limit. All experiments have stopped; the server is under orchestrator control.
