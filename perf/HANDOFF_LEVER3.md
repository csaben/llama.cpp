## Round 2 experiment log

The starting tree is 2b01a78. The baseline libraries from cdef6ff are in build/p7l3/base-libs. The fresh four-depth benchmark uses those libraries and the common GPU0 environment above. The floor probe captures the 193 live matrix descriptors and snapshots each routed selection immediately before consumption during the first single-token step after the 200-token corpus prefix. The timing comparison used the same weight addresses and Q8_1 inputs in both schedules.

The first probe measured 2,006,498,304 bytes over 193 matvecs. All 2,494,400 output rows passed the stock-dot comparison. At 16 rows/tile and 128 threads, the resident dot took 2.69 ms, the stock 193-node graph 2.87-2.90 ms, and the matched 193-node tiled graph 3.53 ms. The corrected volatile read control took 2.34 ms. This triggers the real dense-chain branch. [Raw times](p7l3r2/floor-first.txt), [captured routes](p7l3r2/routes.txt)

The first real dense visit fuses both IQ4_NL matrices, the Q8 attention scan, the short convolution and its state writes. A per-KV-head instruction list releases attention from the last input-tile producer. All 48 visits ran in one cooperative launch each and preserved the 64-row reference logit hash. The first trace cost 37.78 us/visit versus 31.79 us for the stock graph. The two-stage control was slower. The measured kernels used 128 or 168 registers/thread. Follow-up screens varied scheduling, register budget and output-weight staging. [Visit trace](p7l3r2/visit-first.txt), [floor launch sweep](p7l3r2/floor-sweep.txt)

The late-gate schedule reaches the first visit-level win. It streams the 5,528/5,592 scan-input rows first, overlaps the remaining 3,072 gate rows with attention, and applies the gate when the scan ends. A single cooperative kernel ran in 31.63 us vs 31.84 us for the same-build graph. A three-launch schedule took 31.32 us at 24 gate CTAs/head. Both matched the reference logit file. A deeper task queue with shared-memory cp.async staging and 2-4 CTAs/SM was slower. The following experiment extended across the output convolution into the real expert router. [Traces](p7l3r2/gate-traces.txt), [queue](p7l3r2/queue-screen.txt), [gate](p7l3r2/gate-screen.txt), [three-launch screen](p7l3r2/stage-screen.txt)

The extension through routing ran at 24 visits/token and preserved the full reference logits. Its projection workers and 16 preloading router CTAs shared a cooperative grid. It lost the paired tg128 runs to the dense schedule alone. The upstream mix experiment also covers the true residual mix, normalization and packing while workers use cp.async on up to 56 rows each. The follow-up tag includes both extensions and the separate gate-stream and long-scan variants. [Router comparison](p7l3r2/router-trace.txt), [paired tg128](p7l3r2/router-screen.txt), [mix sweep](p7l3r2/mix-screen.txt)

Splitting the long-cache block into eight attention warps and four parallel gate warps gave 217.22/198.83/187.20/173.19 tok/s in the first four-depth sweep. The 8+8 configuration lost. A second short-context layout packs the same IQ4_NL codes before their FP16 scales per row and joins QKV with WO at load time. Both packed schedules match the reference logit hash. The following experiment folded the eight-expert reduction and recurrent update directly into the down rows. [Warp screen](p7l3r2/warps.txt), [layout screen](p7l3r2/pack-screen.txt)

The layout-enabled floor probe checked three distinct, live 48-visit routing traces at corpus positions 200, 212 and 248. Native and lossless dense-packed layouts both stayed below 2.81 ms in this build. The expert experiment permutes unchanged Q2_0 bits so each dp4a input needs two fewer byte-permute instructions. At all 44 eligible visits, a second kernel joins all eight expert slots per output tile and applies the real FFN convolution/state update. The traced 4-row native-weight fusion took 12.70 us versus 12.17 us for the graph pair. The real mix extension ran at 24 of 48 visits. The selected implementation kept the gate overlap and reused the graph allocator and existing output projection. [Three-route audit](p7l3r2/layout-floor.txt)

## Round 3 experiment log

Round 3 starts at dcbdf7b (Round 2 code e03d993). The fresh archived 16264c6 run measured 216.00/197.92/186.05/171.50 tok/s. The Round 2 build measured 222.84/205.23/187.89/174.54. A fresh 119-token GPU0 trace ranks the router-to-up, mix-to-controller-down and controller-down-to-apply boundaries first by aggregate within-token gap. Node tracing slightly overlaps timestamps on some serialized kernels. The much larger softcap-to-next-input interval crosses the host token boundary. [Baseline](p7l3r3/base.txt), [Round 2 control](p7l3r3/r2.txt), [edge costs](p7l3r3/control-edges.txt)

At 82 CTAs the empty graph cost 0.668 us/edge, cooperative sync 0.651, point-to-point release/acquire 0.352, and one producer with acknowledgement from all workers 0.817. These slopes subtract the 128-edge median from the 1,024-edge median. The 1.90x point-to-point advantage triggers a real resident visit. First test is router and routed Q2_K gate/up, using the production-rounded tiled dot. At 48 visits, four ideal pairwise replacements save just 0.061 ms; improvements to useful work and overlap must supply the rest. [Dependency benchmark](p7l3r3/dependency.cu), [measurement](p7l3r3/dependency.txt)

The flag-synced router/up visit now fires at 42 of the 44 Q2_K visits in the token. The other two have a message-producing kernel between the operations. It runs the exact Round 2 16-row tiled dot after the last router block releases each resident CTA. One/two/three CTAs per SM took 47.168/33.553/30.921 us against roughly 26.7 us for the pair. All 64 full-vocabulary rows matched at each setting. Smaller standalone router blocks (1/2/4 expert rows) also matched but failed to beat eight. Further experiments target the next ranked edge and the complete FFN visit. [Router tiles](p7l3r3/router-tiles.txt), [flag visit](p7l3r3/route-visit.txt)

A complete FFN visit now runs from the residual mix and router through routed gate/up, SITU and Q8 packing, down, eight-expert sum and the recurrent state update in one launch. Per-expert counters release down tiles, then per-output-tile counters release the sum. Across 42 matched visits it preserved all 64 vocabulary rows at all three residency settings. Its best traced interval was 62.171 us, so the incremental test rules out scaling this schedule to a full token. Three real controller graph branches also ran, starting the message dot alongside the state mix, the preceding projection/FFN tail, or attention. All produced the reference logits. [Matched spans](p7l3r3/matched-ffn.txt), [full visits](p7l3r3/full-visit.txt), [branch screens](p7l3r3/branches.txt)

The complete short-context attention-through-FFN kernel reached 19 direct visits/token. It runs both IQ4_NL dense matvecs, per-KV-head attention, the first recurrent update, routing, both expert matvecs, SITU, sum and the second update. At 96.10 us/visit it loses the matched eight-launch chain and preserves the 64-row reference. The two-row-per-block mixed-state/controller-down fusion separately took 6.683 us at 46 visits, and the resident down/apply pair took 7.082 us at all 48 controller calls. Register-staged four-row routing took 7.057 us vs 7.269 for eight shared rows.
