# Stream A experiments

Physical GPU1 is CUDA0 in the two-card processes. GPU0 is CUDA1. The target has 200,058 vocabulary entries and 201,024 padded output rows. The folded drafter scores its 32K shortlist.

| Placement or implementation | Evidence and interpretation |
|---|---|
| Separate drafter | With only the primary registered for target compute, the short-edit ABBA legs measured 339.1 / 285.7 / 285.0 / 343.0 tok/s. With both devices registered they measured 351.4 / 307.9 / 302.1 / 337.0. Each set of twelve replies matched the p9 plain response. Each verification still consumes the proposed IDs, and the next draft consumes the committed target feature. [Placement and digests](placement.txt) |
| Generic tensor and row splitting | Tensor mode rejected the target architecture at load. Row mode found no split buffer on the CUDA backend. [Load errors](builtin-split.txt) |
| Native output projection | Half the rows run on each card. The first implementation copied the upper logits back. Zero-depth ABBA measured 240.26 / 246.97 / 247.04 / 242.34 tok/s. Short edit measured 350.2 / 357.4 / 355.1 / 354.5, with identical output. [Paired pilot](native-pilot.txt) |
| Direct output projection | The peer stores its half of the output directly into the destination on the primary. Widths 1-7 preserve the reduction within each weight row. Width 8 uses the ordinary projection and return-copy path. The primary retains the full head for wide prompt batches. [Post-residency kernel measurements](direct-profile-after.tsv), [operator comparison](checks/release-head-test.txt) |
| Routed experts | Tags `p11a-expert-events` and `p11a-expert-flags` replicate the weight banks and split the eight selected experts by slot. The initial partition was four per card. Flags reduce synchronization overhead, but each routed visit still transfers the activation and routes, then waits for the remote result. The experiment measured those costs on both ranks. [Event profile](event-profile.tsv), [flag profile](flags-profile.tsv) |
| Expert variants | Local tags preserve weighted-prefix reduction, direct down-projection stores, a fused down projection, heavy-layer selection, asymmetric slot counts and single-column sharding. Prefix accumulation preserves slot order. Five primary and three peer slots shift work toward the primary while the peer receives input. These paths require their own model-output verification. |
| Attention and controllers | `p11a-attention-gates` sends gate-row projection to the peer during the target KV scan. `p11a-controllers` overlaps invariant controller products with primary work. Short visits pay the fork and join on each use. The separate head-sharded attention probe uses resident Q8_0 KV and compares every output float against the same one-card kernel. |
| Drafter transport | `p11a-draft-anchor` replicates the anchor weights. `p11a-draft-rows` reads returned feature rows and draft IDs on the consuming device, with cross-device events ordering the access. These changes still leave a dependency between consecutive speculative rounds. |
| Layer placement | Moving a table or whole layers can extend a slot by moving memory. Reusing logical layers with another device exposed a mixed-expert graph assertion at 327,680 tokens after prompt evaluation. `p11a-capacity-placement` looks up the physical expert buffers. A slot is credited only after a full request matches the reference. [Earlier memory runs](background.md) |

The calibrated and uncensored models differ in 217 of 704 weight tensors. Their output heads have the same SHA-256. The calibrated PPL figures in the brief and the fresh uncensored results use separate controls. [Model comparison](model-comparison.txt).
